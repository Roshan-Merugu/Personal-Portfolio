# Roshan Merugu — Portfolio

Personal portfolio of **Roshan Merugu**, Full-Stack Developer focused on secure, modern web experiences.

- React 18 + TypeScript
- Vite
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
